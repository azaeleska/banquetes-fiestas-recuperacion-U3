# Reglas de Negocio - Momentos Especiales

1. Cada cliente debe tener nombre, teléfono y correo antes de poder registrarse.
2. Cada evento debe estar relacionado con un cliente registrado.
3. Todo evento debe tener fecha, tipo, ubicación, número de invitados, paquete y estado.
4. El número de invitados debe ser mayor que cero.
5. Para apartar una fecha se debe registrar un anticipo.
6. El saldo de una cotización se calcula restando el anticipo al subtotal.
7. Un evento confirmado no puede cancelarse sin registrar el motivo de la cancelación.
8. Los cambios en la fecha, paquete o número de invitados deben quedar registrados antes de contratar servicios nuevos.
9. Solo los usuarios con un rol válido pueden acceder al sistema.
10. Los estados permitidos para un evento son: cotizado, apartado, confirmado, en preparación, realizado y cancelado.
