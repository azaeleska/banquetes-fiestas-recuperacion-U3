# Plan del Proyecto - Sistema de Administración de Banquetes y Fiestas

## Alcance
El proyecto consiste en desarrollar un prototipo web para registrar clientes, eventos, paquetes, cotizaciones, anticipos, proveedores, recursos, agenda y estados del servicio.

## Fuera de alcance
- Pagos en línea.
- Aplicación móvil.
- Integración con sistemas externos de facturación.

## Estructura de Desglose del Trabajo (EDT)

1. Planeación
   - Definir alcance.
   - Elaborar cronograma.
   - Definir reglas de negocio.

2. Diseño
   - Crear wireframes.
   - Diseñar modelo de datos.

3. Desarrollo
   - Crear formulario de login.
   - Aplicar validaciones.

4. Pruebas
   - Probar inicio de sesión.
   - Registrar evidencias de prueba.
